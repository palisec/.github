# Code of conduct

Palisec's repositories, issues, pull requests and discussions are a professional space.

**Expected:** be respectful and constructive, assume good faith, keep feedback about the work, and accept that maintainers make the final call on what is merged.

**Not acceptable:** harassment, insults or personal attacks, discriminatory language, publishing someone's private information, spam, and posting other people's secrets or keys.

**Enforcement:** maintainers may edit or remove content, and block accounts that break these rules. Report problems privately to admin@palisec.tech; reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
